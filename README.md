# Projeto de Data Analytics com Power BI

Repositório destinado ao desafio de projeto da DIO.

## Status

Planejado. A implementação e os arquivos finais serão
adicionados posteriormente.

## Objetivo

Aprimorar um relatório financeiro no Power BI, organizando
os visuais e os recursos de navegação para facilitar a
análise dos dados e a experiência do usuário.

## Etapas previstas

- [ ] Analisar o relatório criativo disponibilizado.
- [ ] Revisar os gráficos e a apresentação das métricas.
- [ ] Criar uma matriz de descrição de vendas.
- [ ] Ajustar posicionamento, contraste e proporção dos visuais.
- [ ] Organizar os dados e visuais em seções relacionadas.
- [ ] Padronizar o layout das três páginas.
- [ ] Criar botões e menus de navegação.
- [ ] Ajustar os estados de interação dos botões.
- [ ] Testar o relatório e documentar as alterações.

## Entregáveis previstos

- Arquivo do relatório no formato `.pbix`.
- Capturas das páginas.
- Documentação das alterações e funcionalidades.
